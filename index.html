01 / WORKFLOW

从文件到日程From file to calendar

01

接收通知Receive

Windows 通知文件通过 Syncthing 同步至个人 Ubuntu 服务器。Syncthing syncs notification files from Windows to my Ubuntu server.

02

理解事项Understand

Codex AI 分析通知正文，提取行动事项、日期表述与原文依据。Codex AI analyzes notification text and extracts tasks, date expressions and supporting evidence.

03

核对日历Reconcile

查询主日历并检查重复；正式写入模式下创建或按规则更新事件，随后回读确认。Checks the primary calendar for duplicates; live mode creates or updates events under defined rules, then reads them back to confirm.

04

归档与复核Archive & review

成功确认且归档和同步检查通过后归档原件；无法处理的事项保留并汇总为中文人工清单。Archives originals after confirmation and archive/sync checks; unresolved items remain for a Chinese manual-review list.
